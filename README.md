# Персональный сайт-портфолио

Одностраничное портфолио full-stack разработчика Кирилла Ненашева.  
Реализовано на **React + TypeScript** с использованием **GSAP** и **Tailwind CSS**.

## 🚀 Стек

- React 19
- TypeScript
- Vite
- Tailwind CSS
- GSAP
- React Hook Form
- React Icons

## ✨ Особенности

- Адаптивная вёрстка
- Плавные анимации при скролле (GSAP + ScrollTrigger)
- Интерактивные карточки проектов
- Форма обратной связи (mailto)
- Тёмная тема
